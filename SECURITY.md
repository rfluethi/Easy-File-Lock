# Security Policy

## Supported Versions

Only the latest released version receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

Please **do not** report security issues via public GitHub Issues.

Instead, use one of these channels:

- **GitHub Security Advisories (preferred):** https://github.com/rfluethi/Easy-File-Lock/security/advisories/new
- **Email:** mail@rfluethi.com

We acknowledge reports within 5 business days and aim to ship a fix within 30 days for high/critical findings. Please include:

- Affected version / commit hash
- Reproduction steps
- Impact assessment

Thank you for helping keep the project safe.
